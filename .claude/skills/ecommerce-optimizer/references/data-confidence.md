# 数据可信度体系（Data Confidence）

> 混合数据模式下，每个方案结论必须标注数据可信度。本文件定义三级分类、标注规范、交叉验证规则。
> 核心原则：**永不编造数据。找不到就标注"未检索到公开数据"。**

## 一、三级分类

| 等级 | 定义 | 标识符 | 示例 |
|------|------|--------|------|
| **A级（真实抓取）** | 通过 WebSearch / WebFetch / web-access（CDP）直接获取的公开可查数据，可附带来源链接 | `[A-来源URL]` | 竞品页面可见销量排名、公开榜单价格、评价区好评率 |
| **B级（商家提供）** | 商家提供的后台数据、经营报表、截图等，无法由第三方独立验证 | `[B-商家提供]` | 后台转化率、精确客单价、成本结构、ROI 数据 |
| **C级（领域推理）** | Claude 基于电商领域知识和公开信息做出的推理判断，无可直接引用的数据源 | `[C-领域推理]` | 市场趋势判断、竞争格局定性、某策略的预期效果评估 |

## 二、标注规范

### 2.1 通用格式

每个方案结论必须标注可信度：

```markdown
**结论**：建议将主图改为场景化风格，预期提升点击率。
**可信度**：[A-淘宝搜索页] + [C-领域推理]（点击率提升幅度为推理估计，需 A/B 测试验证）
```

### 2.2 组合标注

一个结论可能混合多个数据源，用 `+` 连接：

```markdown
**可信度**：[A-竞品详情页] + [B-商家提供] + [C-领域推理]
```

### 2.3 数据缺口标注

- 找不到的数据：`[未检索到公开数据]`，不猜测、不编造。
- 商家未提供：`[B-商家未提供]`，相关结论降级为 C 级。
- 权限不足无法抓取：`[A-无权限未抓取]`，降级为 C 级。

### 2.4 可信度降级链

```
A级（真实抓取） ──权限不足/反爬/找不到──→ C级（领域推理，标注原因）
B级（商家提供） ──商家拒绝/未提供──────→ C级（领域推理，标注原因）
```

## 三、可信度交叉验证规则

| 规则 | 说明 |
|------|------|
| 双源验证 | A 级结论尽量用 2 个独立来源交叉验证（如平台榜单 + 搜索引擎二手信息一致） |
| 矛盾处理 | 两源矛盾时，标注矛盾，取更有证据力的，并说明 |
| 时间标记 | 所有 A 级数据标注采集日期（市场数据会过期） |
| 抽样说明 | 若只抓取了部分数据（如前 10 名），明确说明抽样范围 |
| 反爬降级 | 抓取失败（反爬/登录墙）→ 降级为 C 级，标注原因 |

## 四、低可信度强制提示

任何结论中 C 级成分占比 >50% 时，必须附加：

```markdown
> **⚠ 低可信度提示**：此结论主要基于领域知识推理，未找到直接可引用的公开数据验证。
> 建议在实际执行前进行小规模测试验证，不要直接大规模投入。
```

**触发条件**：
- 单个结论 C 级占比 >50%
- 整份方案中 C 级结论数占比 >50%
- 商家拒绝提供关键数据导致 P6-P8 依赖该数据的模块大量降级

**低可信度方案的附加处理**：
- 在方案开头加"数据缺口说明"章节，列出所有降级模块
- 对降级模块给出"验证先行"的执行建议（小样本测试/低预算试投）

## 五、各阶段数据来源对照

| 阶段 | 主要数据 | 默认可信度 |
|------|---------|-----------|
| P1 商家输入 | 商家描述/资料 | B 级 |
| P2 产品诊断 | 商家数据 + 品类基准（联网查） | B + C 级 |
| P3 市场调研/对标 | 公开榜单/竞品页/社媒 | A 级为主 |
| P4 方案草案 | 综合 P1-P3 | A/B/C 混合，逐条标注 |
| P5 回答审查 | 商家对问题的回答 | B 级（审查其合理性） |
| P6-P8 方案/内容/活动 | 基于前序 + 领域知识 | 标注比例 |
| P9 交付 | 全部整合 | 汇总分布 |
| P10 归档 | 脱敏后经验 | 存档 |

## 六、可信度汇总表（交付时附在方案末尾）

```markdown
## 数据可信度总览

| 数据类别 | A级(真实抓取) | B级(商家提供) | C级(领域推理) | 占比 |
|---------|-------------|-------------|-------------|------|
| 市场数据 | 8 | 0 | 3 | A 73% |
| 竞品数据 | 15 | 2 | 5 | A 68% |
| 经营数据 | 0 | 6 | 2 | B 75% |
| 策略建议 | 0 | 0 | 12 | C 100% |

**说明**：策略建议部分以领域推理为主，执行前请小规模验证。
```

## 七、与归档的关系

- 归档时记录本次案例的"数据可得性"情况（哪些数据拿得到、哪些拿不到），供自学习。
- 归档中只保留脱敏后的数据（行业级指标），不保留具体经营数字。
