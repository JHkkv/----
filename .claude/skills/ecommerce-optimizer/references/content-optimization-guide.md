# 内容优化方法论（Content Optimization Guide）

> content-optimizer 和 short-video-scriptwriter Agent 的方法论依据。
> 覆盖：主图 / 详情页 / 标题 / 营销文案 / 短视频脚本。

## 一、标题优化

### 1.1 平台字数限制与权重

| 平台 | 标题限制 | 权重特点 |
|------|---------|---------|
| 淘宝/天猫 | 60 字（30 汉字） | 核心词前置，前 10 字权重最高 |
| 拼多多 | 30 字 | 关键词覆盖，避免堆砌 |
| 抖音电商 | 30 字 | 卖点前置，口语化 |
| 亚马逊 | 200 字符（建议 <80） | 前 80 字符权重最高，核心关键词前置 |

### 1.2 标题公式

```
[核心关键词] + [属性词] + [场景词] + [差异化卖点] + [人群词]
```

**示例**（收纳用品）：
- 原：`收纳箱 大容量 家用整理箱 衣服收纳`
- 新：`【加厚】收纳箱 大容量 抽屉式 家用衣物整理箱 衣柜收纳神器 宿舍租房用`

### 1.3 标题检查清单

- [ ] 核心关键词在标题中，且尽量靠前
- [ ] 包含 1 个差异化卖点（材质/功能/场景）
- [ ] 不堆砌无关关键词（易被判违规）
- [ ] 无绝对化用语、无特殊符号滥用
- [ ] 符合平台字数限制

## 二、主图优化

### 2.1 首图逻辑（决定点击率）

| 原则 | 说明 |
|------|------|
| 一眼看懂卖什么 | 3 秒内明白产品 + 核心卖点 |
| 卖点可量化 | "5层收纳""可承重50kg"优于"大容量" |
| 人群视觉 | 目标人群一看就有共鸣（场景/风格） |
| 对比强烈 | 与同屏竞品形成视觉差异（背景/色调/构图） |

### 2.2 主图风格方向（按品类选）

| 品类 | 适合风格 | 案例 |
|------|---------|------|
| 家居/收纳 | 场景化（真实使用场景）+ 白底（专业感） | 衣柜里的收纳箱实拍 |
| 美妆/护肤 | 高质感 + 效果对比 | 使用前后对比 |
| 数码/3C | 科技感 + 参数可视化 | 深色背景 + 参数标注 |
| 食品 | 食欲感 + 原料展示 | 热腾腾的美食实拍 |
| 母婴 | 安全 + 场景 + 温度 | 宝宝使用实拍 |

### 2.3 主图结构建议（5 张图分工）

| 图序 | 用途 |
|------|------|
| 图1 | 首图：卖什么 + 核心卖点（一眼懂） |
| 图2 | 卖点深度：3 个卖点可视化 |
| 图3 | 场景图：真实使用场景 |
| 图4 | 对比图：与同类产品对比/细节放大 |
| 图5 | 信任图：资质/评价/售后保障 |

### 2.4 视频主图（可选增强）

- 15-30 秒：产品使用演示
- 前 3 秒必须有吸引力（截流）
- 含字幕（静音环境可看）

## 三、详情页优化

### 3.1 结构模型（黄金模型）

```
1. 首屏暴击：核心卖点 + 视觉冲击（1 屏）
2. 痛点共鸣：目标人群的痛点场景（1-2 屏）
3. 卖点展开：3-5 个卖点，每个一屏（3-5 屏）
4. 细节信任：材质/工艺/规格/检测（2-3 屏）
5. 对比说服：与竞品/旧款对比（1-2 屏）
6. 场景延展：多场景使用（1-2 屏）
7. 评价证言：好评截图/真实反馈（1 屏）
8. 服务保障：售后/发货/退换（1 屏）
9. 活动引导：当前优惠 + 促单 CTA（1 屏）
```

### 3.2 每屏原则

- 一屏一个信息点（不贪多）
- 文字少而精（每屏 ≤15 字主文案）
- 图片为主，文字为辅
- 视觉节奏：强-弱-强（避免全程平铺）

### 3.3 信任元素清单

- 检测报告 / 质检证书
- 资质认证（如食品 SC 证、3C 认证）
- 真实买家秀（非摆拍）
- 售后承诺（如实，无虚假）
- 品牌背书（如有）

## 四、营销文案

### 4.1 卖点文案公式

```
[场景痛点] + [产品解决] + [可感知结果] + [行动引导]
```

**示例**：
> "衣柜乱到爆？一个抽屉式收纳箱，5 层分区，换季衣物一目了然。今天下单送分隔板，让找衣服不再翻箱倒柜。"

### 4.2 文案类型清单

| 类型 | 用途 | 公式 |
|------|------|------|
| 主图文案 | 首图卖点 | 短句 + 数字 + 人群词 |
| 详情文案 | 详情页各屏 | 痛点 → 卖点 → 信任 |
| 活动文案 | 促销期 | 优惠 + 时限（如实）+ 行动 |
| 标题文案 | 搜索/广告 | 关键词 + 卖点 + 场景 |
| 种草文案 | 社媒 | 故事 + 使用体验 + 真实感 |

### 4.3 文案合规自查

- 无绝对化用语
- 无虚假功效
- 无虚假价格/时限
- 卖点来自真实产品信息

## 五、短视频带货脚本

### 5.1 黄金结构（5 段式）

```
0-5s   钩子：反常识 / 痛点直击 / 身份共鸣 / 效果展示
5-20s  痛点：目标人群的具体生活场景
20-40s 卖点：3 个核心卖点，场景化呈现
40-50s 信任：真实使用 / 对比 / 用户证言
50-60s CTA：引导下单/收藏（不做违规导流）
```

### 5.2 钩子类型（首 3 秒决定完播）

| 类型 | 示例 |
|------|------|
| 反常识 | "用了 3 年才知道，收纳箱要这么选" |
| 痛点直击 | "衣柜乱到每次找衣服都想哭？" |
| 身份共鸣 | "租房党的衣柜收纳救星来了" |
| 效果展示 | "看，3 分钟衣柜变整齐" |
| 数字冲击 | "1 个箱子装下 20 件冬衣" |

### 5.3 分镜表格式

| 时间码 | 画面 | 口播文案 | 字幕 | 音效/音乐 |
|--------|------|---------|------|----------|
| 0-3s | 乱衣柜特写 | "衣柜乱到不想打开？" | 大字幕：衣柜救星 | 紧张音效 |
| 3-8s | 收纳箱入场 | "这个抽屉式收纳箱，一层解决一个季节" | 产品名 | 转场音 |
| ... | ... | ... | ... | ... |

### 5.4 脚本合规自查

- 无诱导互动（"点赞过万公布"）
- 无违规导流（加微信/公众号）
- 无绝对化用语/虚假功效
- 卖点来自真实产品信息
- 直播间版本：避免直播间违禁词

## 六、A/B 测试建议

所有内容优化都建议 A/B 测试验证，不直接全量替换：

| 优化项 | 测试方法 |
|--------|---------|
| 主图 | 同一商品两张主图，各跑 3-7 天，对比点击率 |
| 标题 | 记录搜索排名和点击率变化 |
| 详情页 | 对比转化率（浏览→下单） |
| 文案 | 小范围投放对比点击/转化 |
| 脚本 | 先投测试流量，看完播率和转化 |

## 七、与对标的关系

内容优化方向**优先参考对标结论**（competitor-benchmarker 的可借鉴策略）：
- 主图风格 → 参考对标对象的主图方向（不抄袭）
- 卖点表达 → 参考爆品的卖点切入点
- 脚本结构 → 参考销量榜前十的内容形式
