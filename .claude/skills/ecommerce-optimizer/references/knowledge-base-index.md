**更新规则**：
- 每次 P10 归档后更新本表 + archive/INDEX.md。
- 重复出现 2-3 次的策略 → 升级为"推荐策略"。
- 重复踩坑 → 升级为"预警项"。

## 四、规则更新机制

| 触发 | 动作 |
|------|------|
| 归档发现平台新规 | 更新 compliance-rules.md + platform-configs.md |
| 归档显示某类数据普遍拿不到 | 方案设计主动降级该类数据依赖 |
| 归档显示商家普遍拒绝某类问题 | 优化提问方式或降级该数据依赖 |
| 归档显示某策略重复有效 | 提升为推荐策略（进 benchmark-methodology.md） |

## 五、与外部知识库的联动

- 高质量方案产出可"回存"到外部知识库 `raw/`（闭环回存协议）。
- 外部知识库的新电商素材（如平台规则更新）可回流本 Skill 的领域知识层。
