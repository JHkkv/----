# 交付物模板库（Deliverable Templates）

> P9 交付与各阶段确认点的输出格式标准。所有交付物使用 Markdown，结构统一，便于商家执行和后续归档。

## 一、交付物总览

| # | 交付物 | 对应阶段 | 模板 |
|---|--------|---------|------|
| 1 | 商家档案 | P1 | 模板 1 |
| 2 | 产品诊断报告 | P2 | 模板 2 |
| 3 | 市场调研报告 | P3 | 模板 3 |
| 4 | 竞品对标矩阵 | P3 | 模板 4 |
| 5 | 投流分析报告 | P3（可选） | 模板 5 |
| 6 | 优化方案草案 + 商家问题清单 | P4 | 模板 6 |
| 7 | 合理性审查报告 | P5 | 模板 7 |

## 二、模板

### 模板 1：商家档案

```markdown
# 商家档案

> 建档日期：{日期} | 平台：{平台}

## 基本信息
| 字段 | 值 | 可信度 |
|------|-----|--------|
| 品类 | {品类} | B |
| 核心单品 | {单品} | B |
| 店铺规模 | {月销/层级} | B |
| 客单价 | {价格} | B |
| 上架时长 | {时长} | B |
| 核心痛点 | {痛点} | B |

## 经营数据
| 指标 | 值 | 可信度 |
|------|-----|--------|
| 转化率 | {X%} | B |
| 流量结构 | {占比} | B |
| 好评率/差评类型 | {数据} | B |
| 复购率 | {数据} | B |

## 数据缺口
- {缺失的数据项} → 相关诊断降级为 C 级
```

## 三、格式规范

1. **统一 Markdown**：所有交付物用 Markdown，表格对齐。
2. **可信度标注**：所有数据性结论标注 `[A/B/C]`。
3. **免责声明**：方案类交付物末尾附免责声明。
4. **版本管理**：草案标 v0.x，细化标 v1.0，修正后升版本。
5. **确认门记录**：每个确认门都记录，追溯方案决策链。

## 四、交付物与归档

- 完整方案包交付后，进入 P10 归档：提取脱敏经验，按 archive-self-learning.md 生成归档文件。
- 归档文件不含商家身份/具体经营数字/真实 URL。
