# 平台配置层（Platform Configs）

> 本文档定义 4 个主要平台的配置差异。P0 阶段商家选平台后，读取本文件生成**平台配置快照**，全局生效。
> 设计原则：一套方法论适配多平台，平台差异收敛到本文件这一处。

## 一、平台总览

| 平台 | 电商模式 | 核心流量逻辑 | 内容重心 |
|------|---------|------------|---------|
| 淘宝/天猫 | 货架电商 | 搜索 + 推荐 + 活动 | 主图/详情页/标题/评价 |
| 拼多多 | 货架电商（低价） | 搜索 + 场景 + 活动 | 价格力/主图/评价/活动 |
| 抖音电商 | 兴趣电商 | 推荐流 + 短视频 + 直播 | 短视频/直播/达人/内容投流 |
| 亚马逊 | 跨境货架电商 | 搜索 + 广告 | Listing/A+/评价/广告 |

## 三、榜单数据源

> 付费工具（生意参谋/多多情报通/蝉妈妈/Jungle Scout 等）**默认不可用**。用公开可查的数据源替代，且必须标注可信度等级。

| 平台 | 付费工具（不可用） | 公开替代数据源 | 采集方式 |
|------|------------------|--------------|---------|
| 淘宝/天猫 | 生意参谋 | 淘宝搜索综合排序前 20、天猫榜单公开页、类目热销榜 | WebSearch + WebFetch / web-access（CDP） |
| 拼多多 | 多多情报通 | 拼多多搜索排序、类目畅销榜公开页 | WebSearch + web-access（CDP） |
| 抖音电商 | 蝉妈妈/飞瓜 | 抖音搜索排序、直播/短视频榜公开页、商品热卖榜 | WebSearch + web-access（CDP） |
| 亚马逊 | Jungle Scout/Helium 10 | Amazon Best Sellers、前台搜索排序、New Releases 榜 | WebSearch + WebFetch |

**搜索关键词模板**（WebSearch 用）：

| 平台 | 搜索关键词模板 |
|------|--------------|
| 淘宝/天猫 | `{品类} 淘宝热销榜` / `{品类} 天猫榜单` / `{品类} 类目 TOP10` |
| 拼多多 | `{品类} 拼多多热销榜` / `{品类} 畅销榜` / `{品类} 拼多多销量` |
| 抖音电商 | `{品类} 抖音热卖榜` / `{品类} 抖音爆款` / `{品类} 带货 销量` |
| 亚马逊 | `Best Seller {品类} site:amazon.com` / `{品类} best sellers rank` |

> 抓取失败或反爬时，标注"未检索到公开榜单数据"，改用 WebSearch 二手信息 + 领域推理（可信度降级为 C）。

## 六、合规差异

> 完整合规红线见 `compliance-rules.md`。此处仅列各平台**额外**红线。

| 平台 | 额外审查项 |
|------|----------|
| 淘宝/天猫 | 食品/保健品类审查功效声称；化妆品审查功效测试报告引用；禁用"假一赔十"等承诺用语（除非授权）；"正品保证"需授权证明 |
| 拼多多 | 额外审查虚假低价（划线价与实际售价差距过大）；图片盗图检测更严；不可出现其他平台名称；低价引流后强制搭售属违规 |
| 抖音电商 | 额外审查诱导互动（"点赞过万公布价格"）；违规导流到微信/公众号；直播间违禁词；低价引流（低价商品但实际不是） |
| 亚马逊 | FTC 合规（虚假评论/虚假稀缺性"Only 3 left"）；FDA 声明（保健品/食品）；专利/商标侵权审查更严；review 操纵封号红线 |

## 八、平台未覆盖时的处理

- 商家平台不在 4 个默认平台内（如京东、快手电商、视频号小店）：按最接近的模式套用（京东≈淘宝货架电商，快手/视频号≈抖音兴趣电商），并在快照中标注"近似套用 {平台} 模式"。
- 多平台商家：可先选主平台做深度方案，再输出"多平台差异提示"附录。

## 九、与归档自学习的关系

- 归档案例按平台维度分类存储（`archive/{platform}/YYYY-MM-{品类}.md`），便于 P1.5 自学习按平台检索。
- 平台配置若发现更新（如平台新规则），可在归档的自学习索引中记录，供后续案例引用。
