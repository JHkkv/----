# 合规红线（Compliance Rules）

> content-reviewer Agent 的审查依据。电商广告法通用红线 + 各平台违禁词 + 审查清单。
> 审查原则：**宁严勿松**——放过一个违禁词可能让商家被平台处罚。

## 一、电商广告法通用红线（封禁级）

| # | 红线 | 说明 | 示例 |
|---|------|------|------|
| 1 | **绝对化用语** | 禁用"最好/第一/唯一/国家级/全网最低/史上最/绝对"等 | "全网最低价""最好用的""第一品牌" |
| 2 | **虚假宣传** | 功效虚假、材质虚假、来源虚假 | "7天美白""真皮"(实际PU)、"进口"(实际国产) |
| 3 | **价格欺诈** | 虚构原价、虚假划线价、"仅今日"虚假时间限制 | "原价999现价99"(从未卖过999) |
| 4 | **肖像侵权** | 未经授权使用明星/网红/KOL 肖像或名字 | 用明星照片做宣传图 |
| 5 | **贬低竞品** | 直接或间接贬低竞争对手 | "XX品牌质量差" |
| 6 | **数据造假** | 编造销量、好评率、用户评价 | 虚构"月销10万" |
| 7 | **虚假紧迫感** | 虚假库存/时间限制 | "仅剩3件"(实际大量库存) |
| 8 | **比较级违规** | 无依据的"比XX好/更XX" | "比竞品更耐用"(无检测依据) |

## 二、各平台额外红线

| 平台 | 额外审查项 |
|------|----------|
| **淘宝/天猫** | 食品/保健品类审查功效声称（"增强免疫力"需资质）；化妆品审查功效测试报告引用；禁用"假一赔十"等承诺用语（除非有授权）；"正品保证"需授权证明 |
| **拼多多** | 额外审查虚假低价（划线价与实际售价差距过大）；图片盗图检测更严；不可出现其他平台名称；低价引流后强制搭售属违规 |
| **抖音电商** | 额外审查诱导互动（"点赞过万公布价格""转发抽奖"）；违规导流（加微信/公众号/QQ/引导线下交易）；直播间违禁词；低价引流（标低价实际不是） |
| **亚马逊** | FTC 合规（虚假评论/虚假稀缺性"Only 3 left"）；FDA 声明（保健品/食品）；专利/商标侵权审查更严；review 操纵（刷评/诱导好评）封号红线 |

## 三、平台违禁词库

### 3.1 通用违禁词（全部平台）

```
最 / 第一 / 唯一 / 国家级 / 世界级 / 全网最低 / 史上最 / 绝对 /
顶级 / 极品 / 全网第一 / 全国第一 / 最高级 / 最佳 / 冠军 / 首选 /
百分百 / 100% 有效 / 根治 / 特效 / 万能 / 纯天然（需资质）/
无副作用 / 永不复发 / 仅此一家 / 秒杀（非活动期间）/
假一赔十 / 正品保证（无授权时） / 点击有惊喜（诱导）/
微信 / 加我 / 公众号（无资质导流时）
```

### 3.2 淘宝/天猫附加

```
全网最低价 / 出厂价 / 批发价（无凭证）/ 特价（无来源）/
美白（无特证）/ 瘦身 / 丰胸 / 增高（功效类需特证）
```

### 3.3 拼多多附加

```
禁止出现：淘宝 / 京东 / 天猫 等其他平台名
低价引流（标 0.01 元实际不同商品）
```

### 3.4 抖音电商附加

```
点赞过万公布 / 转发抽奖 / 关注抽奖（违规互动）
加微信 / 加QQ / 线下交易 / 私聊（违规导流）
直播间：绝对化用语 + 功效承诺 + 诱导互动
```

### 3.5 亚马逊附加

```
#1 Best Seller（需真实排名）
FDA Approved（需真实认证）
free shipping（需如实）
100% 退款保证（需真实政策）
Only 3 left（需真实库存）
```

## 四、内容审查必检清单（content-reviewer 逐条过）

- [ ] 无绝对化用语（最/第一/国家级/唯一/全网最低价）
- [ ] 无虚假功效承诺
- [ ] 无虚构价格/虚假划线价
- [ ] 无肖像/字体/图片版权侵权风险
- [ ] 无贬低竞品表述
- [ ] 数据类声称有据可查（标注可信度等级）
- [ ] 无平台违禁词（对照本平台违禁词库）
- [ ] 不诱导违规导流（外链/微信号/公众号/二维码）
- [ ] 不制造虚假紧迫感（"仅剩X件""最后X小时"需真实）
- [ ] 不做刷单/补单/虚假交易建议
- [ ] 不推荐具体违规服务商
- [ ] 食品/化妆品/保健品无功效声称（除非有认证文件）
- [ ] 不承诺具体销量提升数字（用"预期"并标注可信度）
- [ ] 无抄袭竞品文案/图片（可借鉴思路，不复制内容）

## 五、审查严重程度分级

| 级别 | 含义 | 处理 |
|------|------|------|
| **封禁级** | 触碰平台红线，可能导致商品下架/封店 | 必须修改，不通过 |
| **高危** | 可能导致限流/处罚/投诉 | 必须修改 |
| **中** | 潜在风险，可能被举报 | 建议修改 |
| **低** | 表述不够严谨 | 可选优化 |

**封禁级触发条件**：绝对化用语 / 虚假功效 / 虚假价格 / 肖像侵权 / 贬低竞品 / 数据造假 / 违规导流。

## 六、审查报告格式

```markdown
## 合规审查报告

> 审查对象：{内容类型} | 审查日期：{日期} | 平台：{平台}

### 一、逐条审查结果
| 审查项 | 问题定位 | 严重程度 | 处理建议 |
|--------|---------|---------|---------|
| 绝对化用语 | "全网最低价" | 封禁级 | 改为"价格优惠，可对比" |
| ... | ... | ... | ... |

### 二、需修改项清单
1. 原文：{内容} → 问题：{问题} → 建议：{修改建议}

### 三、最终裁定
- [ ] 通过
- [ ] 有条件通过（条件：{列表}）
- [ ] 不通过（理由：{列表}）

### 四、数据可信度复核
- 有无来源的数据声称？→ {有/无}
- C 级高占比结论是否附加强制提示？→ {是/否}
```

## 七、与 GATE-2 的区别

| 层级 | 执行者 | 审查对象 | 时机 |
|------|-------|---------|------|
| content-reviewer（子 Agent） | 子 Agent | 产出内容（文案/脚本/活动）的合规 + 合理性 | P7 终审 |
| GATE-2（主 Agent） | 主 Agent | 商家回答的合理性（R1-R5） | P5 |
| 两者 | - | 层不同，互不替代 | - |

## 八、合规更新机制

- 平台规则会变（如新违禁词、新监管要求），content-reviewer 审查前可 WebSearch 确认最新平台规则。
- 审查时发现的新违禁词 → 记录到本文件（追加），并在归档时记入自学习索引。
