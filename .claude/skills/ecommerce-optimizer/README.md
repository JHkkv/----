# 电商商家运营优化引擎（Ecommerce Optimizer）

面向电商商家的**全流程运营优化 Skill**。商家输入自身情况（语言描述或数据资料），Skill 通过**多 Agent 流水线**制定一套可执行的运营优化方案——对标爆品与销量榜前十，多渠道交叉对比，方案经确认门把关后才执行。

## 核心能力

| 能力 | 说明 |
|------|------|
| **多 Agent 流水线** | 8 个子 Agent 按任务弹性激活（≥4 个），覆盖诊断/调研/对标/投流/内容/活动/审查 |
| **对标驱动** | 优化方案优先对标**爆品 + 近期销量榜前十**，多渠道交叉对比 |
| **确认门机制** | GATE-1（方案草案+向商家提问）+ GATE-2（回答合理性审查）**不可跳过**，回答不合理**直接拒绝执行** |
| **数据可信度** | 每个结论标注 A（真实抓取）/ B（商家提供）/ C（领域推理）三级，低可信度结论强制提示 |
| **合规前置** | 所有产出经内容审查官终审，对照电商广告法与平台违禁词库 |
| **归档自学习** | 每次使用后脱敏归档 → 推送私人仓库 → 新案例自动检索历史经验注入 |

## 支持平台

淘宝/天猫、拼多多、抖音电商、亚马逊（一套方法论，平台细节可切换）。其他平台近似套用最接近的模式。

## 多 Agent 流水线

| # | Agent | 阶段 | 输出 |
|---|-------|------|------|
| 1 | 产品诊断官 | P2 | 7 维度诊断报告 |
| 2 | 市场调研员 | P3 | 市场调研报告 |
| 3 | 竞品对标官 | P3 | 对标矩阵（≥5 对象） |
| 4 | 投流分析师 | P3 可选 | 投流拆解 |
| 5 | 内容优化师 | P7 | 商品页优化 |
| 6 | 短视频脚本师 | P7 | 带货脚本 |
| 7 | 活动策划师 | P7/P8 | 活动方案 |
| 8 | 内容审查官 | P7 终审 | 合规审查 |

## 状态机（P0-P10）

```
触发 → P0权限+平台 → P1商家输入 → P1.5自学习注入 → P2诊断 → P3调研对标
→ P4草案+提问(GATE-1强制) → P5回答审查(GATE-2强制) → P6细化方案
→ P7内容生产 → P8配套活动 → P9交付 → P10归档自学习
```

## 使用方法

### 触发

对 Claude 说（任选其一）：
- "帮我优化店铺"
- "商家诊断" / "店铺诊断" / "运营优化方案"
- "帮我看看我的店" / "怎么提高销量"
- "竞品分析" / "投流策略" / "电商文案优化" / "短视频带货脚本"
- "淘宝店铺诊断" / "拼多多怎么起量" / "抖音小店怎么运营" / "亚马逊运营优化"

### 执行流程

1. **P0 权限确认 + 平台选择**：Skill 展示权限清单并询问，选择目标平台
2. **P1 商家输入**：提供产品情况（描述或数据资料/截图）
3. **P2-P3 诊断 + 对标**：7 维度诊断 + 爆品/销量榜前十对标
4. **P4 GATE-1**：出示具体方案 + 向商家提问（必须回答）
5. **P5 GATE-2**：审查回答合理性，合理→执行，不合理→拒绝
6. **P6-P8 方案细化 + 内容生产 + 配套活动**
7. **P9 交付**：完整方案包
8. **P10 归档**：脱敏归档推送私人仓库，供自学习

### 控制指令

| 用户说 | 效果 |
|--------|------|
| "跳过确认 / 快速模式" | 跳过非强制确认点（GATE-1/2 仍强制） |
| "回到上一步" | 回溯 |
| "换平台" | 重新选平台 |
| "只看竞品分析" / "只要文案" | 模块化裁剪 |
| "停止" | 立即结束，输出已产出 |

## 数据来源说明

| 数据类别 | 获取方式 | 可信度 |
|---------|---------|--------|
| 公开榜单/竞品页 | WebSearch / WebFetch / web-access（CDP） | A 级 |
| 商家后台数据 | 商家提供（截图/报表/描述） | B 级 |
| 付费工具数据（生意参谋/蝉妈妈等） | **不可用**，用公开替代源 | - |
| 领域知识 | Claude 电商领域知识 | C 级 |

## 隐私与归档

- **脱敏归档**：归档只存方法论经验 + 泛化行业数据，不含商家身份/具体经营数字/真实 URL
- **私人仓库**：只推送到 `git@github.com:JHkkv/-.git`（本人私有仓库）
- **自学习**：新案例启动时检索相似归档，注入历史有效策略与踩坑经验
