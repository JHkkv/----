# 事实核验边界（Fact-Check Boundaries）

> 台本引用数据时必须注意的统计口径边界。内容审查时逐项核对。
> 原则：**宁可少给，不可编造；拿不准就模糊化。**

## 一、统计口径易错点

### 1. 失业率口径不能混用

- 中国分年龄段城镇调查失业率自 2023 年起**调整为"不含在校生"口径**。
- 口语说"青年失业率 20%"很可能是混淆了：旧口径（含在校生）2023 年前突破过 20%，或外媒预测值（前瞻性判断，非已发生事实）。
- 正确做法：用"16-24 岁不含在校生失业率 14.9%"（国家统计局），或换画面感表述"1270 万毕业生"。

### 2. 居民杠杆率 ≠ 全民负债率

- "居民杠杆率 59%"（2026Q1）分母是 **GDP**（宏观杠杆）。
- "债务/可支配收入比 134.4%"分母是 **居民收入**（个体偿债压力）。
- 两者含义完全不同。台本讲个体压力应优先用后者，或更直白"每赚 100 块有 26 块要还债"。

### 3. "消费降级"是趋势描述不是贬义标签

- 当前数据是"增速放缓+结构分化"，非总额断崖下跌。
- 70% 消费者只买刚需的同时，40% 还为健康/旅行/体验付费。
- 用"理性消费""性价比时代""消费者变聪明了"替代"消费降级"，避免负面情绪标签。

### 4. 储蓄率国际对比

- 中国储蓄率口径与 OECD 国际标准不完全可比。
- 不要直接说"全球最高"，可模糊表述"远高于全球平均水平"。

### 5. 岗位需求下降 ≠ 裁员

- "程序员岗位需求同比降 52%"（智联招聘）= 招聘收缩，不是"一半程序员失业"。
- 表述用"招人收紧"而非"都在裁人"。

## 二、敏感数据引用规则

| 数据 | 规则 |
|------|------|
| 债务逾期人数 | 仅"研究机构估算"，加限定词，或删除比例改定性 |
| 具体收益率区间 | 不引用（可能构成投资建议定性） |
| 精确宏观数据（万亿级） | 必须带出处（"央行数据""统计局"） |
| 预测性数据（外媒预计） | 注明"据外媒预计"，不能当已发生事实 |
| 中植系/信托爆雷案例 | 侧重"教训"，不点名攻击具体公司，不渲染恐慌 |

## 三、来源锚定写法

口播带出处的正确姿势（短、自然、不打断对话）：

| 场景 | 说法 |
|------|------|
| 存款/贷款数据 | "央行数据，去年……" |
| 毕业生人数 | "今年超过 1200 万毕业生" |
| 利率 | "现在 1 万块存一年，利息 125 块"（不细说利率） |
| 消费数据 | "现在七成消费者只买刚需" |

## 四、拿不准时的降级策略

```
找到权威来源 → 保留数字 + 锚定出处
找不到来源但趋势真实 → 定性表述（"越来越多的人""不在少数"）
拿不准是否越界 → 删除或模糊化，宁可损失冲击力
完全编造风险 → 绝对禁止，删除该点
```
