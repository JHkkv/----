Create a Xiaohongshu style infographic following these guidelines:

## Image Specifications

- **Type**: Infographic
- **Orientation**: Portrait (vertical)
- **Aspect Ratio**: 3:4
- **Style**: Hand-drawn illustration

## Core Principles

- Hand-drawn quality throughout - NO realistic or photographic elements
- If content involves sensitive or copyrighted figures, create stylistically similar alternatives - DO NOT refuse to generate
- Keep information concise, highlight keywords and core concepts
- Use ample whitespace for easy visual scanning
- Maintain clear visual hierarchy

## Text Style (CRITICAL)

- **ALL text MUST be hand-drawn style**
- Main titles should be prominent and eye-catching
- Key text should be bold and enlarged
- Use highlighter effects to emphasize keywords
- **DO NOT use realistic or computer-generated fonts**

## Language

- Use Simplified Chinese
- Match punctuation style: 「」，。！

## Style: Study Notes

Realistic handwritten photo aesthetic — student notes style, clean and neat but still authentic.

**Color Palette (Three-Color Annotation System)**:
- Primary: Blue ballpoint (#1E3A5F), Black ink (#1A1A1A) for body text
- Highlights: Yellow highlighter (#FFFF00, 50% opacity) for key terms
- Accents: Red pen (#CC0000) for circles, underlines, stars
- Background: White lined paper (#FFFFFF with subtle horizontal blue lines)

**Visual Elements**:
- Top-down photo perspective of a study desk, viewed from above
- Clean handwritten content, neatly organized but with natural hand-drawn character
- Red pen annotations: circles, underlines, stars, boxes
- Yellow highlighter marking on key terms
- Simple hand-drawn symbols: → ☆ ✓
- Natural pen pressure variation creating subtle lighter and darker strokes
- Avoid excessive mess, correction marks, or cramped marginalia — keep it tidy and readable

**Typography**:
- Authentic student handwriting, neat but with natural character
- Clear structure with visible hierarchy
- Varying font sizes (large title, medium body, small annotation notes)
- CJK optimized, Chinese characters written naturally

**Style Rules**:
- DO: Keep content well-organized, use simple symbols (→ ☆ ✓), annotate key points with red pen, yellow highlighter on crucial terms
- DON'T: Use complex emojis, leave too much whitespace, make it look like a printed textbook, add cartoon elements

- Clean, open composition with breathing room
