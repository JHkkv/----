## 价值主张

**核心要点（dense layout，5-6 个信息点）**:
1. **是什么**: RAG = Retrieval-Augmented Generation，检索增强生成
2. **为什么需要**: LLM 有知识截止日期 + 幻觉问题，RAG 给它外挂知识库
3. **怎么工作**: 用户提问 → 检索相关文档 → 拼入 Prompt → LLM 生成答案
4. **三大组件**: Retriever（检索器）+ Knowledge Base（知识库）+ Generator（生成器）
5. **能解决什么**: 幻觉降低、知识实时更新、答案可溯源
6. **典型场景**: 企业知识库问答、客服机器人、文档助手
